# 🌊 ReSubmerged Servers

A community directory for **ReSubmerged modded regions**.

ReSubmerged Servers allows players to discover and share community-hosted regions in one place, with a simple underwater-themed interface.

## ✨ Features

- 🌊 Underwater / deep-sea themed design
- 🛰️ Sonar-style animated interface
- 🫧 Animated bubbles and light rays
- 🌍 Community region directory
- 🟢 Online / 🔴 Offline status display
- 👥 Player count display
- 📡 Ping display
- 📋 One-click server address copying
- 📱 Responsive design for desktop and mobile
- ⚓ Community region submission link
- 📄 Regions loaded dynamically from `regions.json`
